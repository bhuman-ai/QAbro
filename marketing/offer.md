# Offer

## Facts

- Product: Before Users Do is a hosted QA MCP and companion skill for coding agents.
- Existing proof: The production product implements browser-backed QA, evidence capture, fix-ready reports, and AI, owner, team, and human testing paths.
- Current behavior: `Install BeforeUsersDo` leads to sign-in, MCP key creation, MCP configuration, skill installation, and a first QA request.
- Current limitation: No customer outcome metrics, testimonials, acquisition attribution, or public pricing were found in the inspected product path.

## Hypothesis

- Audience: Founders and small product teams shipping AI-coded web apps with an MCP-capable coding agent.
- Triggering situation: Their coding agent says a feature is done and the preview is close to shipping, but nobody has produced trustworthy browser QA evidence.
- Painful job: Catch release-blocking bugs and confusing flows without leaving the coding workflow or coordinating QA by hand.
- Promised outcome: Catch bugs and UX friction before users do, with evidence the coding agent can use to fix them.
- Mechanism: One hosted MCP connection plus a companion skill routes the work through AI, self, team, or human QA and returns a fix-ready report.
- Primary objection: Installing another tool feels like work before the builder has seen a concrete result.
- Primary CTA: `Install BeforeUsersDo`
- Primary conversion event: `first_qa_report_completed`

## Message

**One-line offer:** Catch bugs and confusing flows in your AI-coded app before users do—then send the evidence straight back to your coding agent.

**Why now:** The riskiest moment is when generated code looks finished and is about to ship without an independent browser-backed check.

**Why believe it:** Before Users Do already connects the coding agent to browser QA, captures concrete evidence, and returns fix-ready reports through one install path.

**What happens after the CTA:** Create an account, make one MCP key, install the MCP connection and companion skill, then ask the coding agent to test a reachable preview.
